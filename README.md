# Wedding Invitation Website 💍

A modern wedding invitation website inspired by elegant international wedding themes with RSVP system and countdown timer.

## Features

* Wedding countdown timer
* Event schedule cards
* RSVP guest confirmation form
* Guest member count system
* Thank you message after submission
* Responsive modern wedding UI

## Technologies Used

* HTML5
* CSS3
* JavaScript
